# Стоматология Медиа — демонстрационный прототип

Интерактивный прототип главной страницы v3.10 для согласования дизайна.

Откройте `index.html` или опубликованный сайт GitHub Pages. Запись, поиск и переходы демонстрационные; формы не отправляют данные. Часть изображений — синтетические концепты по предоставленным референсам. Это не действующий официальный сайт клиники.

Публикация: Settings → Pages → Deploy from a branch → main → /(root).
